# TerroirMap - Step 3

STEP 1の地図・施設詳細機能に、次の機能を追加した版です。

- お気に入り登録／解除
- お気に入り一覧
- 現在地へ移動（ブラウザの位置情報許可が必要）
- 日本語／英語切り替え
- お気に入りと言語設定をブラウザ内（localStorage）に保存

## 更新方法
既存のGitHubリポジトリにあるファイルを、このZIP内の同じ名前のファイルで置き換えてください。`index.html`、`css/style.css`、`js/map.js`、`js/app.js`、`data/facilities.json`を更新します。

## お気に入りの保存について
お気に入りと言語設定は利用者の端末のブラウザ内に保存されます。アカウントや自前サーバーへの送信はありません。ブラウザのデータを消去すると保存内容も消える場合があります。

## 現在地について
現在地ボタンを押したときだけ、ブラウザの位置情報機能を利用します。利用にはHTTPS接続と利用者の許可が必要です。位置情報はこのアプリの自前サーバーや施設データには送信しません。ただし地図タイルの取得先には通常の地図閲覧通信が発生します。

## サンプルデータについて
施設6件は架空の動作確認用データです。実在施設ではありません。一般公開前に確認済みの実在施設データに置き換えてください。
